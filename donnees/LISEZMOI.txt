Projet Data Storage Systems · groupe 10 · Coopérative agricole
Données FICTIVES générées pour votre groupe seulement (aucune personne réelle). Encodage UTF-8, séparateur virgule.

fermes.csv    le siège (id 1) et les trois sites : Angers, Laval, Le Mans
clients.csv    les usagers ; id_ferme = site de rattachement
paniers.csv  les ressources datées (une par panier) : site, début, durée, capacité en places, prix unitaire
commandes.csv   les opérations : usager, ressource, date de l'opération, nombre de places, montant, statut
            (CONFIRMEE ou ANNULEE), id_groupe = opération groupée passée en une fois (vide sinon)

Le site d'une opération est celui de sa ressource. Le pic de trafic de votre sujet : fêtes de fin d'année.

Ces fichiers contiennent volontairement des défauts, comme des données réelles : à vous de les détecter,
de décider comment votre modèle les traite (refus par une contrainte, correction, rejet tracé) et de le
justifier. Les définitions des valeurs de contrôle sont dans le sujet du projet.
